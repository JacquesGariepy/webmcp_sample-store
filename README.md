# webmcp_sample-store: the tk store behind JacquesGariepy/webmcp_sample

Event-sourced shared state for the coding agents of this team (tk 0.4). `tk.config.json` holds the projects, their repositories and tracker writes; `projects/<project>/events/<actor>.jsonl` is the append-only source of truth, one file per person or agent; one commit per action, authored by the actor.

- Never edit files under `projects/` by hand. Use `tk` from a code repository mapped here.
- `CODEOWNERS` is generated by `tk project add --owners`; protect `main` and require review.
- CI (`.github/workflows/tk-validate.yml`) runs `tk config`, `tk validate` and `tk status --all` on every push and pull request: unreadable lines, schema drift, unknown dependencies and contested claims fail the build until a person resolves them.
- `git.autoSync` is `commit`; developers and agents run `tk sync` (Claude Code does it in the SessionStart hook).

How this store was created and used: https://github.com/JacquesGariepy/webmcp_sample/blob/main/WALKTHROUGH.md
